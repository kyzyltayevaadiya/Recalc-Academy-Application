# AGENTS.md

## Project Context

A standalone Vite + React app (no external backend/platform dependency). Start with
`README.md` for local setup.

## Key Files

- `src/`: frontend application source.
- `src/lib/questData.js`: all narrative content for the RPG journey.
- `vite.config.js`: Vite config.

## Working Notes

- Use `npm run dev` for local development.
- Run the relevant checks from `package.json` (`lint`, `typecheck`, `build`) before finishing code changes.
